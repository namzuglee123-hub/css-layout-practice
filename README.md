# CSS Layout Practice

Learning how to lay out a website with CSS Grid and Flexbox.

## What I built
- Page skeleton with CSS Grid (header, sidebar, content, footer)
- Header and menu with Flexbox
- Responsive card gallery using `repeat(auto-fit, minmax())`
- Mobile layout using a media query

## What I learned
- The parent defines the layout, and the children follow
- Grid for 2 directions, Flexbox for 1 direction
- `fr` is a share of the leftover space
